# OQUE É UMA LISTA?

Uma lista é uma coleção ordenada e mutável de itens, que pode conter elementos de diferentes tipos de dados, como números, strings, ou até outras listas. As listas são delimitadas por colchetes: [], e os itens são separados por vírgulas.
## CRIANDO UMA LISTA
Você pode criar uma lista em Python simplesmente colocando os itens entre colchetes. Por exemplo:
```python
minha_lista = [1, 2, 3, 'quatro', 'cinco']
