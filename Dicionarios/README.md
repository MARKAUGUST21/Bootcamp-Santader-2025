## Criando um dicionario

Um dicionario  é um conjunto nao-ordenado de pares chave: valor, onde as chaves sao unicas em uma dada instancia do dicionario. Dicionarios são delimitados por chaves: {}, e contem uma lista de pares de chaves: valor separada por virgula

## O que é um dicionario aninhado

Um dicionario aninhado é um dicionario que contem outro dicionario como valor associado a uma chave. Isso permite criar estruturas de dados mais complexas e hierarquicas.
